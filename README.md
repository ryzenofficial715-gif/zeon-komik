# 📚 Zeon Komik

- 🔥 50+ komik populer
- 🔍 Search komik
- 📖 Baca chapter full
- 💬 Komentar & React
- 🔖 Bookmark (Google login)
- 🛡️ Anti-scrape

- Firebase Auth
